## До публичной публикации
- Подтверждённые сведения о распространителе и актуальные юридические документы (не выдумывать личные данные).
- Постоянный релизный ключ подписи, резервная копия ключа; пароли и файлы ключа вне GitHub. Debug APK не использовать для публикации. Конфигурация подписи принимает четыре переменные окружения ZABERI_KEYSTORE_PATH, ZABERI_STORE_PASSWORD, ZABERI_KEY_ALIAS, ZABERI_KEY_PASSWORD. Для публикации использовать `gradle assembleRelease -PzaberiPublishableRelease=true -PzaberiBannerId=...`; отсутствие ключа или production ID завершит сборку ошибкой.
- Производственный идентификатор баннера Яндекса, проверка реального объявления и настроек согласия. Debug использует демонстрационный блок, release без идентификатора не показывает рекламу.
- Заполнить карточку RuStore, возрастную категорию, описание, актуальные скриншоты и иконку; проверить действующие требования магазина перед загрузкой.
- Собрать и проверить подписанный релизный APK, убедиться в правильном applicationId и версии, протестировать обновление между подписанными версиями.
- Публикация и слияние в main только после подтверждения готовности.

Никаких изменений схемы Room или формата резервной копии в RC7.
