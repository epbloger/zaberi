# Реклама и сторонние сервисы
Редакция от 25 ноября 2026 года · основная тестовая версия 0.5.0

## Текущее состояние
В основной версии Забери реклама и рекламный SDK отсутствуют. Для проверки интеграции Яндекса существует отдельная тестовая сборка, не являющаяся частью этой версии.

## Внешние сервисы
При открытии ссылки на магазин или страницу поддержки действуют правила соответствующего внешнего сервиса. Названия магазинов приводятся только для идентификации покупок.

## Будущие изменения
Перед включением рекламы в основной версии информация о поставщике рекламы, обработке технических данных, доступных настройках и применимых согласиях будет обновлена. Основные функции учёта должны оставаться доступны без интернета.
